# AI Data Analyst Agent

AI-powered data analyst that uses an LLM to answer business questions from structured datasets using SQL, Pandas, Statistics, and Plotly.

## Features

- Natural-language data analysis
- SQL and Pandas tools
- Statistical analysis with SciPy
- Plotly visualizations
- LangChain tool calling
- LangGraph agent workflow
- Local LLM with Ollama and Llama 3.2

## Tech Stack

Python • Pandas • SQLite • SQL • SciPy • Plotly • LangChain • LangGraph • Ollama

## Dataset

Superstore Sales Dataset containing sales, profit, quantity, discount, category, region, customer, and product information.

## Example Questions

- Which category has the highest sales?
- What is the average profit?
- Which region generates the most profit?
- What is the correlation between sales and profit?
- Show sales by category.
