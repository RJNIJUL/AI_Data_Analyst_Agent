 AI Data Analyst Agent

An AI-powered data analyst that uses an LLM to answer business questions from structured datasets using SQL, Pandas, Statistics, and Plotly.

🚀 Features
Natural-language data analysis
SQL tool for business queries
Pandas analysis tool
Statistical analysis with SciPy
Interactive Plotly visualizations
LangChain tool calling
LangGraph agent workflow
Local LLM using Ollama + Llama 3.2
🛠️ Tech Stack

Python • Pandas • SQLite • SQL • SciPy • Plotly • LangChain • LangGraph • Ollama • Llama 3.2

📊 Dataset

Superstore Sales Dataset containing sales, profit, quantity, discount, category, region, customer, and product information.
